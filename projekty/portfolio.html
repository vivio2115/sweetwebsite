🖥️ Strona portfolio

Webowa strona portfolio, prezentująca moje umiejętności i projekty. Zbudowana w HTML, CSS i JS.

Opis projektu

Strona portfolio to moja wizytówka w sieci, gdzie prezentuję swoje umiejętności, projekty i osiągnięcia. Jest zbudowana w HTML, CSS i JavaScript, co pozwala mi na pełną kontrolę nad wyglądem i funkcjonalnością. Strona jest responsywna, szybka i nowoczesna.

Technologie

HTML5 CSS3 JavaScript
  • Preloader i animacje wejścia
  • Responsywność (mobile first)
  • Nowoczesny design (czysty CSS, bez frameworków)

Status

  • Stan: aktywnie rozwijany
  • Ostatnia aktualizacja: lipiec 2025

Roadmapa

  • Przepisanie strony do Laravel – więcej możliwości rozwoju strony
  • Lepsza optymalizacja mobilna – poprawki dla najmniejszych ekranów
  • Angielska wersja strony – przełącznik języka

Changelog

  • 2025-07-29: Start projektu, pierwsza wersja portfolio
