# Portfolio Website - vivio

A modern, responsive portfolio website showcasing backend development skills and projects.

## 🚀 Features

### Performance Optimizations
- **Lazy Loading**: Images load only when needed
- **Resource Preloading**: Critical assets are preloaded
- **Optimized CSS**: Custom properties and efficient selectors
- **Minimal JavaScript**: Lightweight, vanilla JS implementation
- **Compressed Assets**: Optimized images and fonts

### Accessibility (WCAG 2.1 AA Compliant)
- **Keyboard Navigation**: Full keyboard accessibility
- **Screen Reader Support**: Proper ARIA labels and semantic HTML
- **Focus Management**: Visible focus indicators
- **Skip Links**: Quick navigation for assistive technologies
- **Reduced Motion**: Respects user motion preferences

### Modern Design
- **Mobile-First**: Responsive design starting from mobile
- **Design System**: Consistent spacing, colors, and typography
- **Micro-interactions**: Subtle animations and hover effects
- **Dark Mode Support**: Automatic dark mode detection
- **Print Styles**: Optimized for printing

### Technical Features
- **Semantic HTML5**: Proper document structure
- **CSS Grid & Flexbox**: Modern layout techniques
- **Intersection Observer**: Efficient scroll-based animations
- **Service Worker Ready**: PWA capabilities
- **SEO Optimized**: Meta tags and structured data

## 🛠️ Technologies Used

- **HTML5**: Semantic markup with microdata
- **CSS3**: Custom properties, Grid, Flexbox
- **Vanilla JavaScript**: ES6+ features, no frameworks
- **Font Awesome**: Icon library
- **Google Fonts**: Inter font family
